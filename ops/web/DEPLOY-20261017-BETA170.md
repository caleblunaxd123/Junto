## Distribución

Crear grupo grande y permanente en Inicio; grupos con total y saldo por persona;
actividad reciente. Creación con nombre/personas primero y país/moneda/fecha
plegables. Gasto con pagador, participantes y reparto visibles; voz/boleta opcionales.
El grupo abre en Cuentas y Chat conserva novedades, mensajes, borrador y adjuntos.
Consultar cuentas no marca la conversación como leída; las notificaciones de
mensajes abren directamente el chat. Ver [decisión y QA](../../docs/junto-ux-audit/19_DISTRIBUCION_CUENTAS_CHAT_20261017.md).

## Respaldo y reversión

- Respaldo nuevo `/opt/junto/backups/junto-20261017T181400Z.dump`, restaurado en
  una base de ensayo única: 27 migraciones completas, ninguna pendiente.
- El verificador antiguo del servidor intentó reutilizar una base fija existente:
  falló sin sobrescribirla. Se utilizó la versión actual del repositorio como
  `restore-check-20261017-beta170.sh`; solo eliminó su propia base de ensayo al pasar.
  La base antigua no fue tocada.
- Copia externa cifrada DPAPI en `ops/artifacts/junto-20261017T181400Z.dump.dpapi`,
  con autorización específica del dueño. Recuperación/hash verificados; el dump
  sin cifrar permaneció solo en memoria durante la transferencia. Requiere la
  cuenta Windows del dueño. Respaldo original del VPS conservado.
- Se conservaron imagen anterior y todas las descargas previas. Configuración
  activa `/opt/junto-beta/release-20261017-beta170.env`; rollback privado preparado.

Revertir únicamente la web:

```sh
cd /opt/junto-beta
docker compose --env-file rollback-20261017-beta170.env up -d --no-deps --wait web
```

No restaurar la base sobre operaciones nuevas para revertir este cambio visual.
Android no permite instalar una versión con código menor sobre la actual: una
reversión funcional requiere recompilar con código superior y el mismo firmante,
sin desinstalar para no perder datos locales.

Es distribución beta directa, no Play Store/TestFlight. Google físico en esta APK,
push con la app cerrada, TalkBack, dictado con ruido y comprobantes/WhatsApp entre
teléfonos siguen requiriendo pruebas de campo. No se enviaron correos o mensajes
a usuarios reales durante esta publicación.
