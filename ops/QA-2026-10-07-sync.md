## Correcciones adicionales

- Reintentos de gastos: la misma clave con participantes, reparto, categoría, nota o fecha distintos devuelve 409; no muestra silenciosamente un gasto anterior como si fuera el nuevo.
- Comentarios simultáneos: comprobación de duplicados, límite y escritura dentro de una transacción protegida por un bloqueo PostgreSQL por autor. Cinco solicitudes iguales generan un solo registro.
- Comprobantes entre grupos: bloqueos transaccionales por imagen y operación antes de comprobar si están usados. Dos grupos no pueden registrar simultáneamente el mismo comprobante. No se verifica una transferencia bancaria: sigue siendo evidencia revisable.
- Correos: el límite y la reserva del envío son atómicos por remitente, incluso con distintas claves y varias instancias de API. También se bloquea el reenvío inmediato de un resultado incierto; no se afirma que fue entregado.
- Scripts de integración: validación estructural de URLs locales para impedir que un fragmento `localhost` permita tocar una base o API remota. Se admiten bases JUNTO de QA aisladas; cuatro recorridos adicionales entran en CI.
